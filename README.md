## 👋 Hola, soy Carlos

Desarrollador de software de **Oaxaca, México** 🇲🇽, trabajando **100% remoto**. Tengo **3 años de experiencia** entre proyectos freelance y productos propios, con foco en **backend, diseño de APIs REST y arquitectura de software**.

Me gusta construir sistemas completos: desde el esquema de base de datos hasta el pipeline que los despliega en producción. No me quedo en "que funcione": busco que sea **testeable, mantenible y fácil de desplegar y revertir**.

- 🔭 Actualmente construyo **Commons Marketplace** (e-commerce full stack) y **VaniaBot** (producto comercial).
- 🏗️ Me apasiona la **arquitectura limpia** (Onion Architecture) y la lógica de negocio que se prueba sin mocks.
- 🚢 Disfruto la parte de **infraestructura**: Blue/Green, IaC con Ansible, reverse proxies y redes.
- 🧪 Creo en el testing serio: **1,010+ tests** y **80% de cobertura** en mi proyecto principal.
- 👥 Tengo experiencia liderando equipos como **Scrum Master y Tech Lead**.
- 🌱 Aprendiendo: Java 21 / Spring Boot en profundidad, microservicios y mi inglés (rumbo a **B2**).

## 🚀 Proyecto estrella

### 🛒 Commons Marketplace — Ecosistema full stack propio
> *Backend · Client · Deploy* — 2025 – presente

Plataforma de e-commerce completa, diseñada y construida por mí de punta a punta.

| Área | Detalle |
|---|---|
| **Stack** | Node.js / Express · Next.js · PostgreSQL |
| **API** | 50+ endpoints REST con autenticación basada en roles |
| **Arquitectura** | Onion Architecture sobre MVC: lógica de negocio testeable sin mocks |
| **Testing** | 1,010 tests · 80% de cobertura (Jest) |
| **Tiempo real** | Chat con proveedores intercambiables (Socket.io / Ably) detrás de una interfaz de repositorio compartida |
| **Deploy** | Pipeline propio con Ansible + GitHub Actions |
| **Resiliencia** | Blue/Green con rollback automático en **menos de 1 minuto** vía Nginx |
| **Seguridad** | Exposición segura de servicios con VPN (Tailscale) |

**Lo que lo hace especial:** los proveedores de chat se pueden cambiar sin tocar la lógica de negocio, la infraestructura está definida como código y un despliegue fallido se revierte solo.

## 🤖 Proyectos destacados

### 💬 VaniaBot — Producto comercial
> Desarrollador único · Nov 2025 – presente

Bot de WhatsApp **vendido comercialmente por grupo**, construido en TypeScript con Baileys.

- ⚙️ **200+ comandos** en 9 dominios y **80+ servicios integrados**.
- 🧵 **Orquestador multi-instancia:** 50 sesiones concurrentes con estado aislado.
- ❤️‍🩹 **Heartbeat / Recovery Service** para reconexión automática.
- 🔌 **Middleware Pipeline** con fallback de IA (Groq / LLaMA 3) y **Circuit Breaker** por proveedor.
- 🧹 Refactor mayor **v2.0.0**: ~6,800 líneas eliminadas en 177 archivos.
- 🔁 CI/CD con GitHub Actions y Docker · **502 commits**.
